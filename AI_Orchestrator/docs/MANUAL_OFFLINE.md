# Como estudar offline

1. Abre `curso_offline.html` no navegador sem internet.
2. Escolhe milestone e task, lê objetivo, teoria, prática e critérios.
3. Tenta resolver **antes** de abrir a solução.
4. Expande «Revelar solução / código de referência» para comparar com os ficheiros do projeto.
5. Executa comandos e testes por SSH no Raspberry. Regista evidência e assinala a task manualmente.
6. O progresso é guardado localmente no navegador quando suportado. Exporta o ficheiro JSON de progresso para evitar perdas (browser em modo incógnito ou políticas `file://`).
7. O código é uma referência inicial funcional, não uma certificação de que todas as tasks M0–M12 foram encerradas. Operações em Android, MQTT e dispositivos físicos requerem hardware e validação.
